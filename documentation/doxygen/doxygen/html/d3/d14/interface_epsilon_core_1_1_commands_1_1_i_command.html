QueuedCommand EpsilonCore.Commands.ICommand.EnqueueCommandSpecific ( Machine initialMachine)

This function should contain Enqueue logic specific to a particular command. This will perform any checks specific to a particular command and ensure the command is ready to be applied to the initialMachine .

Parameters
initialMachine
Returns
A QueuedCommand containing the QueuedCommand.ResultantMachine which will result when the command is applied and DataPacket which contains the information to send the command to the microcontroller. The DataPacket will exclude the DataPacket.SequenceNumber because that will be assigned right before it is sent to the microcontroller.

List< Duration?> NormalizedActuatorDerivatives (CompositeKinematicSystem kinematicSystem)
 Normalizes the actuator first derivatives based on the actuator's square corner speed. Normalizing by square corner speed is a design choice, not a physical law: there is no single "correct" way to compare a rotary actutors's motion against a linear actuator's motion, since they are not physically commensurate quantities. Square corner speed was chosen because if an actuator cannot handle a large square corner speed, it should probably be the one limiting the square corner speed for the other actuators.

◆ NormalizedActuatorDerivatives()

List< Duration?> EpsilonCore.Motion.MovePoint.NormalizedActuatorDerivatives ( CompositeKinematicSystem kinematicSystem)

Normalizes the actuator first derivatives based on the actuator's square corner speed. Normalizing by square corner speed is a design choice, not a physical law: there is no single "correct" way to compare a rotary actutors's motion against a linear actuator's motion, since they are not physically commensurate quantities. Square corner speed was chosen because if an actuator cannot handle a large square corner speed, it should probably be the one limiting the square corner speed for the other actuators.

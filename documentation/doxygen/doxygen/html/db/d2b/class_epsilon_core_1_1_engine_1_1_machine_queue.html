EpsilonCore.Engine.MachineQueue Class Reference

MachineQueue manages the queue of ICommands for a specific machine. It also keeps track of the latest status update of the machine for things like temperature and position updates. ICommands are first created, then send to CommandsToEnqueue where they wait to be queued to a machine and moved to Queued, then marked ready to send and moved to ReadyToSend, then sent and moved to Sent. Detailed Description

MachineQueue manages the queue of ICommands for a specific machine. It also keeps track of the latest status update of the machine for things like temperature and position updates. ICommands are first created, then send to CommandsToEnqueue where they wait to be queued to a machine and moved to Queued, then marked ready to send and moved to ReadyToSend, then sent and moved to Sent. If a Board sends a message saying that a command failed or an error occurred, every other Board will be notified to shutdown, clear their movment queue, set pins to safe states, etc.

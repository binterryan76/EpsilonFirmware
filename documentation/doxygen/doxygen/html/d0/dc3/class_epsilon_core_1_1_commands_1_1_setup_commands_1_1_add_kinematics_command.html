Detailed Description

Command to add a new set of kinematics to a machine. A single machine has only one MotionSystem and CompositeKinematicSystem but can contain multiple IKinematics.

Parameters
KinematicsKinematic to add.
LineNumber
ActuatorIdsLinearThe ids of the IActuatorLinears used by the Kinematics .
ActuatorIdsRotationalThe ids of the IActuatorRotationals used by the Kinematics .
AxisIdsLinearThe ids of the AxisLinears used by the Kinematics .
AxisIdsRotationalThe ids of the AxisRotationals used by the Kinematics .
EndstopSetsThe EndstopSets used by the Kinematics .
